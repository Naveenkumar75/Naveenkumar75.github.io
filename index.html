Featured project

OmniDesk

A multi-tenant customer-support backend in Go and PostgreSQL, with an AI service that suggests replies from each tenant's own knowledge base.

  • Tenant isolation enforced twice: every query is scoped by the tenant in the JWT, and composite foreign keys make the database reject cross-tenant references.
  • Tickets follow an explicit state machine; status changes take a row lock and write an audit event in one transaction.
  • A background SLA worker uses FOR UPDATE SKIP LOCKED, so several replicas can sweep at once and each breach is recorded exactly once.
  • Admin and agent roles, rate-limited login, versioned migrations, structured logs and an OpenAPI spec kept in sync with the router by a test.
  • A FastAPI service does RAG over pgvector and exposes read-only tools through an MCP server, using the caller's own token.
